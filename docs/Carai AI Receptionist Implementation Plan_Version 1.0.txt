1. Development Strategy

Build Order Principle

We build in this order:

Foundation
     ↓
Business Data
     ↓
AI Brain
     ↓
Customer Interaction
     ↓
Business Actions
     ↓
Revenue Features
     ↓
Advanced Automation

Do not build flashy features before the core loop works.


---

2. MVP Definition

The first sellable version:

A business owner can:

1. Create an account.


2. Create their business profile.


3. Add services/products.


4. Train their AI.


5. Install a chat widget.


6. Receive customer conversations.


7. Capture leads.


8. Receive booking requests.


9. View analytics.



That is enough to charge money.

8. AI Coding Agent Workflow

Since you use AI heavily, we should structure development around agents.

Each task should include:

Context

Goal

Files allowed to modify

Architecture rules

Acceptance criteria

Tests required

Example:

> Build Conversation Service.

Follow existing FastAPI module structure.

Do not place business logic in routes.

Add tests.

Add API documentation.
