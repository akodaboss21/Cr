One thing before we start: although this document uses the term "System Architecture", This will be built as a modular monolith first rather than true microservices. FastAPI is excellent for this. Each module has clear boundaries, but everything deploys as one application initially. As the platform grows, modules can be extracted into separate services without major rewrites.

18. Background Workers

Long-running tasks never block requests.

Examples:

Embedding documents

Sending emails

Generating summaries

Syncing calendars

AI follow-ups

Analytics aggregation

---

19. AI Provider Abstraction

Every provider implements the same interface:

generate()

stream()

embed()

count_tokens()

list_models()

health_check()

Whether the provider is OpenAI, Ollama, or another compatible endpoint, the rest of the application calls the same methods.


---

20. Event System

Modules communicate through events rather than calling each other directly when possible.

Examples:

LeadCreated

AppointmentRequested

AppointmentConfirmed

ConversationStarted

ConversationEnded

BusinessUpdated

CreditsConsumed

KnowledgeUpdated

This makes future integrations with Admin ESA much easier.

22. Multi-Tenancy

Every record includes an Organization ID.

Every query is automatically scoped to that organization.

No cross-organization access.

Ever.


---

23. Deployment

One Docker Compose stack for self-hosting:

FastAPI

PyRunner Worker(s)

Redis (cache and job queue)

Supabase (hosted)

Nginx

Optional Ollama


Scale by adding more worker containers before splitting services.


---

24. Observability

Every request should generate:

Structured logs

Request ID

Organization ID

User ID (if authenticated)

Duration

AI provider used

Tokens consumed

Error details (when applicable)


This will make debugging customer issues much easier.


---

25. Ready for the Ecosystem

This architecture deliberately keeps the boundaries clean:

Admin ESA will orchestrate these modules through APIs and events.

DevOS can extend modules with plugins, custom workflows, and scripts.

Atelier can be called as a creative service when conversations need images, marketing copy, branded documents, or other generated assets.


Nothing in this design assumes those products exist today, but everything is prepared for them.
