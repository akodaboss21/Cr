Carai AI Receptionist

Database Migration & Backend Build Sequence

Version 1.0


---

1. Backend Development Philosophy

The backend is built in layers.

Do not create all tables first.

Build vertical slices.

Meaning:

A small complete feature from database → API → frontend → user value.

Example:

Business Setup:

Database

↓

Backend Service

↓

API Endpoint

↓

Dashboard Screen

↓

Working Feature

8. Definition of Backend MVP Complete

Backend is MVP-ready when:

✅ Business can register

✅ Business can configure services/products

✅ AI can understand business information

✅ Customer can chat

✅ AI can answer questions

✅ AI can capture leads

✅ AI can create appointment requests

✅ Owner can retrieve conversations
