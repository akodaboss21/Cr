---

API Versioning

Use URI versioning:

/api/v1/...

Deprecation policy:

Existing versions receive security fixes.

New features are added without breaking existing clients whenever possible.

Breaking changes only occur in a new major API version.



---

Internal vs Public APIs

Keep a strict distinction:

Public APIs

Stable.

Documented.

Available to customers and partners.


Internal APIs

Used between Carai modules.

Can evolve more quickly.

Never exposed directly outside the platform.


This separation lets Admin ESA, DevOS, and Atelier communicate efficiently without forcing those internal contracts to remain public forever.


---

Ecosystem Readiness

This API is intentionally broader than Carai AI Receptionist.

It already provides extension points for:

Admin ESA to orchestrate business operations.

DevOS to create workflows, plugins, and custom applications.

Atelier to generate creative assets through the shared AI layer.

Future Carai products to share authentication, billing, AI access, and business data without duplicating infrastructure.
