Brand Personality

Carai should feel:

Intelligent

Warm

Trustworthy

Modern

Human


Not:

Cold enterprise software

Sci-fi robot

Generic chatbot

Design Tokens

Clean

Readable

Modern

Components

Required:

Buttons

Inputs

Cards

Tables

AI Visual Language

AI actions should have a distinct identity.

Examples:

AI thinking indicator

AI generated response

Tool execution

Human takeover

Automation running


---

Motion

Use subtle animation:

Page transitions

Loading states

AI typing

Success confirmations


Avoid excessive effects.
