Carai LLM Gateway & AI Runtime Specification

Version 1.0


---

Purpose

The LLM Gateway provides a single AI interface for every Carai product.

No product communicates directly with OpenAI, Ollama, or any other provider.

Instead:

Product

↓

Carai AI Runtime

↓

LLM Gateway

↓

Provider Adapter

↓

Model

This allows providers to be added, removed, or switched without changing application code.

---

Runtime Principles

1. Products never talk directly to LLM providers.


2. All prompts are versioned and stored centrally.


3. All AI actions are auditable.


4. Provider choice is an implementation detail, not an application concern.


5. Memory, knowledge, and tools are first-class citizens—not afterthoughts.


6. Every provider must conform to a common interface.


7. Support OpenAI-compatible endpoints and Ollama from day one.


8. Design for future models without changing product code.
